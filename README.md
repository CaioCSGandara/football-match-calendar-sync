# 🇧🇷 Visão Geral

- Este projeto foi criado com o objetivo de estudar e implementar uma fila de mensageria em um caso de uso real, tendo em vista que servirá de uso pessoal.
- O projeto consiste em uma integração de dados de partidas de futebol, da API-Football, com o Google Calendar, realizando sincronização dos dados e exibindo de maneira atualizada as partidas de diversos campeonatos de futebol do mundo diretamente no calendário.
- Em construção...

---

# 🇺🇸 Overview

- This project was created to study and implement a message queuing architecture in a real-world use case, tailored for personal use.
- The project integrates football match data from API-Football with Google Calendar, syncing data to display up-to-date matches from leagues worldwide directly in the calendar.
- Work in progress...
